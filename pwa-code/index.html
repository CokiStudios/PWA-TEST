🛡️ Acerca de Coki Studios PWA

Esta PWA integra arquitectura de vanguardia para ingeniería web y nativa, almacenamiento local seguro (`localStorage`), servidor Hosted MCP con soporte SSE (`/mcp/sse`) y diseño inspirado en el ecosistema cokistudios.com.
